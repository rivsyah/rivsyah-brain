# reference/ — external-system research

One folder per external system we depend on but don't control. **Label every claim** (§4.9):
`verified` (tested / read the source) · `inferred` (prior knowledge / docs that may lag) ·
`confirm-live` (must be checked against the real system before relying on it). Cite sources. A claim
that drives a build decision must be **verified**, not inferred. Re-verifying a `confirm-live` claim
promotes it to `verified` — note the date.

If the org keeps a wider evidence taxonomy ({{binding: name it and the mapping}}), map these labels
onto it — do NOT run two parallel taxonomies.

Add per-system folders only as you actually research a dependency.
