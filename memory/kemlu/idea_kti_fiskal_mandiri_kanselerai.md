# Ide KTI: sumber fiskal mandiri untuk operasional Kemlu (31 Okt 2026)

Permintaan Aldo: "ide KTI di kemlu terkait kekanselariaan, ekonomi, investasi, mencari sumber fiskal anggaran
mandiri untuk mendukung operasional anggaran kemlu". Dijawab di chat, tanpa cek live baru.

Tidak mengulang [[project-kti-blu-aset-dana-abadi]] (PNBP kekonsuleran -> dana abadi) dan memakai verdict
[[idea-pnbp-proses-bisnis-kemlu]] (jenis PNBP baru = ubah PP 21/2025; tuas utama = izin penggunaan dana PNBP).

Tiga kelompok ide:
- Hemat (ruang fiskal dari efisiensi): selisih kurs PNBP valas setempat (natural hedging), konsolidasi pengadaan
  global Perwakilan (kontrak payung), kontrak hemat energi berbasis kinerja (ESCO), sewa vs beli gedung (life-cycle cost).
- Pendapatan baru: BGS/BSG/KSP/tukar menukar BMN Perwakilan; co-location BUMN di gedung Perwakilan (sewa BMN);
  diklat diplomasi untuk pihak luar (jenis PNBP baru).
- Pembiayaan bersama: co-financing promosi ekonomi dengan BUMN/swasta (hibah/sponsor, bukan PNBP).

Rekomendasi agen: 1) PNBP valas setempat vs selisih kurs (terkait temuan PANTAS, tapi KTI hanya sumber publik);
2) konsolidasi pengadaan Perwakilan (paling dekat peran BUP); 3) optimalisasi BMN Perwakilan (catatan: Aldo pernah
drop "aset" pada KTI dana abadi karena Kemenkeu = Pengelola Barang; di sini Kemlu bertindak sebagai Pengguna Barang
yang mengusulkan).

Status: terbuka. Aldo belum memilih.

31 Okt: ide 5 (BGS/KSP) tumpang tindih objek dengan [[project-kti-bmn-perwakilan-blu]]; di sana BGS/KSP hanya data (0 usulan), belum dianalisis.
