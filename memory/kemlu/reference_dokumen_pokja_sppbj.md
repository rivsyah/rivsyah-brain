Fakta hukum yang sudah dicek live (26 Sep 2026):
- Pasal 33 ayat (3) huruf b Perpres 16/2018 jo. Perpres 46/2025: penawaran terkoreksi < 80% HPS → Jaminan Pelaksanaan
  5% dari nilai HPS (80–100% → 5% nilai kontrak). Wajib untuk kontrak > Rp200 jt. Berlaku sampai serah terima pertama
  pekerjaan konstruksi. Sumber: pasal.id + peraturan.bpk.go.id.
- Perlem LKPP 12/2021 [Likely, dari sumber sekunder]: SPPBJ paling lambat 6 hari kerja setelah laporan Pokja;
  jaminan pelaksanaan + tanda tangan kontrak paling lambat 14 hari kerja setelah SPPBJ.

Cara kerja template (dari Google Docs export, font Arial 12): run-nya sudah bersih, jadi isi dengan ganti teks per
`<w:r>` + sisip `<w:highlight>` sebelum `<w:rtl>`. SPPBJ = kop dari template Pengumuman + badan surat baru (model Perlem 12/2021).
Gambar tanda tangan Aldo di Nodin sengaja dibuang dari draf; blok ttd di Nodin adalah sdt `contentLocked`.
Render/cek: [[reference-office-render]]. Template SPK terkait: [[reference-template-spk]].

- Perlem 12/2021 Lampiran II (konstruksi): penawaran < 80% HPS wajib evaluasi/klarifikasi kewajaran harga. Wajar →
  jaminan pelaksanaan naik jadi 5% HPS; tidak wajar → penawaran gugur.

Celah terbuka: BAHP tidak menyebut klarifikasi kewajaran harga, padahal penawaran pemenang < 80% HPS. Pastikan berita
acara klarifikasinya ada di arsip Pokja sebelum SPPBJ terbit.
