28 Okt 2026. Aldo minta SOP model `Downloads\SOP Jamkes.xlsx` (SOP Mikro Biro Keuangan: kolom No/Aktivitas/Pelaksana/
Mutu Baku/Keterangan + flowchart bentuk Excel) untuk Monitoring dan Evaluasi Jamkes PIMPRI.
Hasil: `Downloads\SOP Monev Jamkes Pimpri.xlsx` (sheet Simbol + "Monev Jamkes"; builder XML di scratchpad sesi, tidak disimpan).

Fakta Permenlu 7/2023 (Peningkatan Manfaat Jamkes Pimpinan Perwakilan beserta Keluarga, 17 Jul 2023, pelaksana Perpres 110/2022):
- Ps 15(1): Kemlu monev pelaksanaan + kinerja Badan Penyelenggara min 1x/tahun; Ps 15(2): dapat libatkan Kemenkes + Kemenkeu.
- Ps 14(2)-(3): pedoman pelaksanaan disusun Badan Penyelenggara dgn libatkan Kemlu, Kemenkes, Kemenkeu; ditetapkan BP setelah persetujuan Menlu.
- Ps 3(2): SK pengangkatan disampaikan ke KPA (tembusan BP) maks 7 hari kerja. Ps 5/8: daftar manfaat.

Alur SOP (10 langkah): Karo Keu terima masukan peserta → Kabag Perbendaharaan → PIC inventarisasi + matriks (3 hr) →
Kabag reviu (revisi/setuju) → Karo teken undangan → rapat koordinasi bersama BP + Kemenkes + Kemenkeu (DSP DJPb selaku KPA) →
PIC laporan + rekomendasi pembaruan pedoman (3 hr) → Kabag reviu → Karo teken surat ke BP → BP pakai sbg data sumber pembaruan pedoman.
Asumsi agent (belum dikonfirmasi): BP = Asuransi Jasindo (ikut SOP Kepesertaan); waktu tiap langkah; isi matriks/laporan; rapat dipimpin Karo.
